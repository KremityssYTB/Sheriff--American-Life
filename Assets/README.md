# Game assets

This folder contains the Unity runtime and editor source for the first Cypress County greybox milestone.

- `Scripts/` contains the initial world blockout, walking, camera, patrol vehicle, and dispatch systems.
- `Editor/ProjectSetup.cs` provides the **SHERIFF → Setup Mobile URP Project** command. Run it once in Unity 6.3 to create the URP pipeline/renderer assets, Main scene, and iOS player settings.
- `Settings/` and `Scenes/` are generated by that editor command when the project is opened in Unity.

The prototype uses placeholder primitives. It is not yet a finished game and has not yet been verified by a successful Unity cloud build.
